### I ran plants. Now I build the systems behind them.

Chemical engineer from Shah Alam, Malaysia. Eight years inside mills, labs and biogas plants, from Kuala Lumpur to Turin to East Kalimantan. Since 2022 I write the software those plants run on: SCADA pipelines, fleet dashboards and reports the people on shift actually read.

In the evenings I run [Ruji Labs](https://rujilabs.com), where I ship products of my own. Most of the code is in private repositories, so this page is the map.
